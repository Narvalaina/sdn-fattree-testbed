# Limitations and claim boundaries

- The primary validated Fat-Tree result is **deterministic RESTCONF forwarding**.
- The ECMP contribution is a **bounded demonstrator** based on OpenFlow `select` groups and measured branch counters.
- The subsequent attempt to extend ECMP more broadly across the Fat-Tree is **exploratory and non-conclusive**; the repository must never describe it as a completed full-ECMP implementation.
- Experiments were executed on a single local Linux testbed. Throughput values describe that emulated environment and are not general performance guarantees.
- Raw run logs are intentionally not published. Compact processed summaries are provided for traceable public claims.
- OpenDaylight RESTCONF examples use HTTP/Basic Authentication because this was a local laboratory setup; this is not a production security recommendation.
- Historical thesis-production files, third-party bibliography PDFs, virtual environments, saved web exports and unverified icon assets are excluded from the public repository.
