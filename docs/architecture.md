# Architecture

The testbed combines a Linux host, Mininet, Open vSwitch (OpenFlow 1.3) and OpenDaylight through RESTCONF and the OpenFlow southbound interface.

## Topology progression

1. **Basic topology** — smallest connectivity and controller-integration checks.
2. **Intermediate topology** — incremental validation before introducing path redundancy.
3. **Leaf-Spine 2-4-2** — controlled multipath experiments.
4. **Fat-Tree k=4** — 4 core, 8 aggregation and 8 edge switches, with 16 hosts and 48 links.

The deterministic Fat-Tree metadata exported in `data/topology/fattree_k4/` is generated by `tfg_sdn/mininet/topos/fattree.py`.

## Control and forwarding

- OpenDaylight programs OpenFlow rules through RESTCONF.
- Open vSwitch provides the datapath and exposes counters used as verification evidence.
- The primary Fat-Tree campaign uses deterministic forwarding.
- ECMP is represented only by bounded/select-group demonstrators; the fuller ECMP work is retained as exploratory evidence.
